# Day 01-Java Challenge
##What I learned
-Java is a high-level, object-oriented programming language. It is platform-independent because it practices the WORA principle, which is write once and run anywhere, due to the JVM.

-There are 3 main environments we should know:
JVM(Java Virtual Machine): it is used to execute the bytecode of Java.
JRE(Java Runtime Environment): traditionally used to run Java programs.
JDK (Java Development Kit): a software kit to develop Java programs.


-The execution process:
lets the code:


        public class Hello{
                 public static void main(string[] args){
                          system.out.println("Hello Java");
                 }
        }


1st,programmer=source code{Hello.java}
2nd,the compiler(javac) change to bytecode{Hello.class}
3rd, JVM execute the bytecode
4rd,out put{Hello java}
